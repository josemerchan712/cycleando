# 🚲 Cycleando — Propuesta Web

Propuesta de página web para **Cycleando**, empresa local de Málaga especializada en la reparación de bicicletas y patinetes eléctricos.

---

## 🌐 Demo en vivo

👉 [cycleando-nueva.netlify.app](https://cycleando-nueva.netlify.app/)

---

## 📋 Descripción

Diseño y desarrollo de una web moderna y responsive para presentar los servicios de Cycleando, facilitar el contacto con clientes y mejorar su presencia digital. El proyecto nació como propuesta para ayudar a un negocio local a dar el salto a internet.

---

## ✨ Características

- Diseño responsive adaptado a móvil, tablet y escritorio
- Sección de servicios ofrecidos
- Información de contacto y localización
- Estética moderna orientada a captar clientes online
